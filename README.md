# ImgTrace

<img src='https://cdn.hackclub.com/01a02960-1e1f-7e12-ac11-17dd8912cb68/image.png'>

ImgTrace is simple image to ASCII converter. It works by first converting the image to grayscale, then converting the scale of how dark the image is to a 1-7 scale which is then used by the program to choose which character to use. It is printed line by line in a nested for loop.

## Installation

You can install the executable at <a href='https://dsochamp.github.io/ImgTrace'>https://dsochamp.github.io/ImgTrace</a>. You can upload any image you like by entering its file location on your device.
